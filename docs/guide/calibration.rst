Site calibration
================

The input profiles describe a typical atmosphere. If you know the mean and the
standard deviation of the temperature and of the precipitable water vapour (PWV)
at your site, pass them to :class:`~atmo3.atmosphere.Atmosphere` to recalibrate
the profiles and the fluctuations. Each statistic is independent and optional:
**anything not provided is not calibrated**.

.. code-block:: python

   atmo = a3.Atmosphere(
       profiles='midlatitude_summer',
       temperature_mean=272.2,   # K
       temperature_std=0.3,      # K
       pwv_mean=1.15,            # mm
       pwv_std=0.03,             # mm
       ...
   )

The same keyword arguments are accepted by
:class:`~atmo3.calibration.AtmosphereCalibrator`, which performs the work.

What each statistic does
------------------------

``temperature_mean``
   The temperature profile is multiplied by a constant so that its value at the
   lowest grid level (the site) equals the given mean.

``temperature_std``
   The temperature fluctuation profile is multiplied by a constant so that its
   value at the lowest grid level equals the given standard deviation. If the
   profiles have no ``'temperature_std'``, the fluctuation is this value at all
   heights. With neither, the default is 0.1 K at all heights.

``pwv_mean``
   The specific-humidity profile is multiplied by a constant so that its
   column-integrated PWV,

   .. math::

      \mathrm{PWV} = \int \rho_{\mathrm{H_2O}}\, dz, \qquad
      \rho_{\mathrm{H_2O}} = q\,\frac{p}{R_{\mathrm{dry}}\,T_v},

   equals the given mean. Because the virtual temperature :math:`T_v` depends on
   :math:`q`, the scaling is iterated until it converges.

``pwv_std``
   Applied each time a water-vapour realization is generated by
   :meth:`~atmo3.atmosphere.Atmosphere.generate_realization`. The field is
   multiplied by a constant so that the standard deviation of its sky-plane PWV
   map equals the given value.

Water-vapour fluctuations
-------------------------

When the profiles include ``'specific_humidity_std'`` (kg kg\ :sup:`-1`), its
height-dependent RMS amplitude is interpolated onto the grid. Otherwise the
amplitude is 0.1 % of the calibrated mean specific-humidity profile. A supplied
RMS profile is not rescaled by ``pwv_mean``; ``pwv_std`` rescales the generated
water-vapour field when provided.

Getting the statistics
----------------------

atmo3 takes the numbers, not a data file, so it does not depend on any
particular weather-station format. For example, with a table of station
measurements:

.. code-block:: python

   import pandas as pd

   df = pd.read_csv(station_file, ...)
   window = df[(df['UT'] >= t - pd.Timedelta(minutes=30)) & (df['UT'] <= t + pd.Timedelta(minutes=30))]
   atmo = a3.Atmosphere(
       profiles=profiles,
       temperature_mean=window['T_K'].mean(), temperature_std=window['T_K'].std(),
       pwv_mean=window['PWV'].mean(),         pwv_std=window['PWV'].std(),
       ...
   )

Calibrated attributes
---------------------

After construction, ``atmo.atm_calibrator`` holds the profiles on the grid:
``temperature_profile``, ``spec_humidity_profile``, ``pressure``,
``vir_temperature``, ``q2rho_h2o``, ``temp_fluctuation_profile`` and
``spec_humidity_fluctuation_profile``.
